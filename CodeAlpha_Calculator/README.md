# 🧮 Modern Interactive Web Calculator

A sleek, responsive, and feature-rich Web Calculator built using **HTML5, CSS3, and Vanilla JavaScript**. Designed with a 3D Neumorphic dark-mode UI, live mathematical previewing, dynamic state management, advanced error safeguards, and full physical keyboard accessibility.

Developed as part of the **Frontend Development Virtual Internship at CodeAlpha**.

---

## ✨ Features

- **🎨 Sleek Dark Aesthetic UI:** Custom-built modern 3D depth design featuring vibrant color-coded key actions and smooth press animations.
- **⚡ Live Mathematical Preview:** Displays the ongoing multi-step equation above the main result display in real time.
- **⌨️ Full Keyboard Accessibility:** Complete physical keyboard support (`0-9`, `+`, `-`, `*`, `/`, `Enter` for calculate, `Backspace` for delete, and `Escape` for clear).
- **🧠 Smart State Tracking:** Prevents result chaining issues when entering fresh numbers after completing a calculation.
- **🛡️ Advanced Error Handling:** Handles edge cases such as division by zero (`Cannot divide by 0`) and syntax errors (`Invalid Syntax`) gracefully without crashing the UI.
- **📱 Responsive Design:** Fully optimized using CSS Grid for seamless viewing across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Grid & Custom Properties)
- **Scripting:** Vanilla JavaScript (ES6+ DOM Manipulation & Event Handling)
- **Version Control:** Git & GitHub

## 💻 Keyboard Controls Reference

| Physical Key    | Calculator Action               |
| --------------- | ------------------------------- |
| `0 – 9`         | Input Digits                    |
| `+, -, *, /, .` | Input Operators / Decimal Point |
| `Enter` or `=`  | Calculate Result (`=`)          |
| `Backspace`     | Delete Single Character (`DEL`) |
| `Escape`        | Clear All Inputs (`C`)          |
