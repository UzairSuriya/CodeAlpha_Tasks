# 🎵 Interactive Web Music Player

A sleek, responsive, and feature-rich Web Music Player built using **HTML5, CSS3, and Vanilla JavaScript**[cite: 2, 4]. Designed with a modern glassmorphic dark/light aesthetic, full HTML5 Audio API integration, interactive progress scrubbing, dynamic playlist management, and persistent theme preferences[cite: 2, 4].

Developed as part of the **Frontend Development Virtual Internship at CodeAlpha**[cite: 2, 4].

## ✨ Features

- **🎨 Executive Glassmorphic UI:** Built with backdrop filters, ambient neon glow highlights, and card elevation styling for a sleek modern music player experience.
- **🌓 Dynamic Dark/Light Theme Switcher:** Seamlessly toggling between a dark synthwave aesthetic and a clean light theme, with user choices saved via `localStorage`.
- **⏯️ HTML5 Audio Engine:** Complete custom playback controls including Play, Pause, Next Track, Previous Track, and automatic progression upon track completion.
- **🎛️ Interactive Progress Scrubbing:** Real-time audio progress tracking with click-to-seek functionality and dynamic duration formatting (`MM:SS`).
- **🔊 Custom Volume Regulation:** Precise range slider control with dynamic icon updates reflecting mute, low, and full volume states.
- **📜 Dynamic Interactive Playlist:** Active track selection menu with visual highlight indicators and seamless switching without page reloads.
- **📱 Fully Responsive Design:** Fluidly optimized across viewports ranging from mobile displays to high-resolution desktop viewports.

## 🎧 Audio Controls Reference

| Action / Interface Element   | Control Description                                    |
| :--------------------------- | :----------------------------------------------------- |
| **Play / Pause Button**      | Toggle audio playback state and animate track artwork  |
| **Backward Step (`⏮`)**     | Navigate to the previous track in the playlist         |
| **Forward Step (`⏭`)**      | Skip to the next track in the playlist                 |
| **Progress Scrub Bar**       | Click anywhere along the bar to seek to that timestamp |
| **Volume Slider**            | Adjust playback loudness from 0% (mute) to 100%        |
| **Playlist Item**            | Click any song title to jump directly to that track    |
| **Theme Switcher (`🌙/☀️`)** | Toggle between dark and light color modes              |
