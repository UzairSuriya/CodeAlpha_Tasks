# 🎵 Interactive Web Music Player

A responsive web music player built using **HTML5, CSS3, and Vanilla JavaScript**. Features audio controls, progress scrubbing, volume adjustment, and dynamic playlist handling via the HTML5 Audio API.

Developed as part of the **Frontend Development Virtual Internship at CodeAlpha**.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Glassmorphic UI, Flexbox)
- **Scripting:** Vanilla JavaScript (HTML5 Audio API, DOM Manipulation)
- **Icons:** FontAwesome v6.4
- **Version Control:** Git & GitHub
