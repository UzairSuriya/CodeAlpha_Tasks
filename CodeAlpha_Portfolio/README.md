# 🌐 Developer Portfolio Site

A modern, responsive, and high-impact Developer Portfolio built using **HTML5, CSS3, and Vanilla JavaScript**. Designed with dynamic dark/light theme switching, interactive project category filtering, active navigation scroll-tracking (ScrollSpy), and an executive glassmorphic aesthetic.

Developed as part of the **Frontend Development Virtual Internship at CodeAlpha**.

---

## ✨ Features

- **🌓 Dynamic Dark/Light Theme Switcher:** Seamlessly toggles between a glassmorphic space-dark mode and a clean executive light mode with persistent theme choices saved via `localStorage`.
- **🎯 Interactive Project Category Filter:** Dynamically filters featured project cards (`All`, `Vanilla JS`, `Web Apps`) without page reloads using JavaScript DOM manipulation.
- **📍 ScrollSpy Navigation:** Automatically tracks scrolling positions and highlights the active section link in the fixed header navigation bar.
- **💼 Internship & Education Timeline:** Dedicated layout showcasing internship experience at CodeAlpha and academic progression at Sir Adamjee Intermediate College.
- **📱 Fully Responsive Layout:** Crafted with modern CSS Grid, Flexbox, and media queries to deliver an optimal experience across desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (CSS Custom Variables, Flexbox, CSS Grid, Glassmorphic UI)
- **Scripting:** Vanilla JavaScript (ES6+ DOM Manipulation, Event Listeners, LocalStorage API)
- **Icons:** FontAwesome (v6.4)
- **Version Control:** Git & GitHub
